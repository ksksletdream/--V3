# 数智算力中心作战白板 — 自由绘制与战术批注增强方案

围绕算力中心大项目攻关复盘、投委会汇报推演与团队协同看图场景，为拓扑白板构建一套完整的**矢量自由绘制与战术批注系统**。所有手绘笔迹、智能几何图形与战术便签均作为独立矢量图元运行，支持点选、拖拽、缩放、改色、图层排序、撤销/重做、SQLite 双端持久化以及 100% 还原的 PNG/SVG/PDF 导出。

## 1. 功能概览与核心价值

- **解决的核心痛点**：在大型算力中心项目（如 32MW 液冷智算中心）的客户关系复盘会上，主责铁三角（AR/SR/FR）不仅需要展示静态组织架构，更需要边讨论边在白板上**圈出友商控标风险区、用战术箭头标出下周高层引荐突破路径、贴上待办攻关便签**，并在会后直接将带有战术批注的作战图导出为投委会汇报战报。
- **目标用户场景**：
  1. **作战研讨与标注**：用自由画笔、荧光笔或一笔成型圆框/箭头，在关键人物卡片与关系连线周围直接做视觉批注。
  2. **汇报演示引导**：开启「演示激光笔」，鼠标划过之处留下高亮发光轨迹并在 1.2 秒内平滑消隐，聚焦听众视线且不污染画布。
  3. **极速拓扑重构**：用套索圈住几个干系人直接点击「生成阵营框」，或用套索划断失效的汇报连线。
  4. **战报归档分享**：一键切换「显示/隐藏手绘批注」，在导出高清 PNG、无损 SVG 或 A4 投委会 PDF 时自由决定是否附带战术批注图层。

## 2. 用户体验与视觉设计规范

### 核心交互流程

1. **浮动工具栏唤起绘制模式**：
   - 在画布可拖拽悬浮工具栏中新增**自由绘制工具组**：
     - `P` **自由画笔 / 荧光笔 / 一笔成型智能笔**（点击展开二级紧凑调色与笔触面板：切换普通钢笔、荧光马克笔、开启/关闭「一笔成型智能识别」、选择 8 种战术色彩与 3 档线宽）。
     - `Z` **演示激光笔**（绘制高亮流光轨迹，停笔后自动渐隐消失）。
     - `N` **作战便签贴纸**（点击画布任意位置放置战术便签，支持双击编辑文字、切换「重点突破 / 风险预警 / 待核实 / 情报纪要」四角印章与底色）。
     - `E` **矢量橡皮擦**（按住拖拽划过任意手绘笔迹或便签即可精准擦除，并支持一键清空当前项目全部批注）。
2. **一笔成型几何规整（Smart Shape Recognition）**：
   - 当开启「智能图形识别」或绘制结束停顿时，系统实时分析手绘点集的闭合度、凸包长宽比与曲率拐点：
     - 近似闭合圆环/椭圆 $\rightarrow$ 自动规整为平滑矢量圆/椭圆框；
     - 近似闭合四边形 $\rightarrow$ 自动规整为圆角战术矩形框；
     - 近似单向折线或末端带钩线条 $\rightarrow$ 自动规整为挺括的直线或带箭头战术指示线。
3. **自由套索（Lasso）双模式升级**：
   - **套索圈选建组**：使用套索 `L` 圈中多个干系人后，或者在空白处手绘闭合圈并点击浮动提示「以此区域新建分组框」，直接按套索包围盒创建阵营框。
   - **划线切断连线（刀切手势）**：在套索工具下按住 `Alt` 键（或在套索子模式切换为「划线切断」），手绘一条红光轨迹穿过 1 条或多条关系连线，松手后自动批量切断并删除被穿过的连线（带撤销支持）。
4. **独立矢量选中与变换体验**：
   - 在选择模式 `V` 下点击任意手绘笔迹、规整图形或作战便签，显示带 4 个角缩放手柄的蓝色虚线包围盒与顶部快捷属性条（快速改色、改粗细、置顶/置底、锁定、删除），支持同人物卡片一起框选并批量移动。

### 视觉与排版规范

- **美学基调**：延续工程级智算作战室的克制、高对比度极客工业风，遵循单层卡片高度（1px 精细边框 `border-slate-200`）与 60-30-10 色彩配比。
- **字体与数字对齐**：UI 标签与便签正文采用 `Plus Jakarta Sans` 与 `Noto Sans SC`；所有坐标、图层 `Z-Index`、笔触粗细参数（如 `2px`、`4px`、`8px`）统一使用 `IBM Plex Mono` 等宽字体与 `tabular-nums`。
- **60fps 流畅动效**：绘制过程直接操作 SVG 路径，笔迹采样含距离阈值滤波与二次贝塞尔中点平滑；激光笔采用 CSS/SVG 透明度衰减动画，交互响应延迟控制在 `16ms` 以内。

## 3. 关键产品与技术决策

- **决策 1：采用「二次贝塞尔中点插值 + Ramer-Douglas-Peucker (RDP) 路径简化」存储矢量笔迹**
  - *方案*：采集鼠标/触控点时先按最小间距（`3px`）过滤抖动，松手时用 RDP 算法精简控制点，并生成平滑的二次贝塞尔 SVG `path` (`M ... Q ...`)，同时记录归一化局部坐标与包围盒（`x, y, width, height`）。
  - *原因*：既保证手绘曲线顺滑无锯齿，又让每条笔迹可以像普通矩形节点一样通过改变 `(x, y, width, height)` 实现零开销的整体拖拽平移与等比缩放，且数据体积縮小 70% 以上。
- **决策 2：客户端几何启发式「一笔成型」识别器**
  - *方案*：基于纯前端几何特征（首尾距离比、路径总长与包围盒周长比、主轴线性回归误差、末端锐角折返检测）在毫秒级判定用户意图（自由曲线 vs 直线 vs 战术箭头 vs 矩形 vs 椭圆）。
  - *原因*：零网络延迟、离线可用，且识别成功后依然保存为结构化矢量属性，后续可随时调整颜色与尺寸。
- **决策 3：图层与导出引擎同源渲染**
  - *方案*：将手绘批注（`DrawingAnnotation`）纳入统一图层序列（默认 `zIndex` 位于 `140+`，支持调整至人物卡片上方或下方），并在 SVG 导出引擎中复用同一套路径生成逻辑。
  - *原因*：确保画布上看到的荧光笔半透明叠加、战术箭头、作战便签在导出为 3x PNG、矢量 SVG 和投委会 PDF 时 100% 像素级一致。

### 核心数据模型定义

1. **手绘与战术批注实体 (`CanvasAnnotation`)**：
   - `id`: 唯一标识
   - `kind`: `'pen'`（自由钢笔） | `'highlighter'`（半透明荧光笔） | `'shape'`（一笔成型几何图形） | `'sticky'`（作战便签贴纸）
   - `shapeType?`: `'rect'` | `'ellipse'` | `'line'` | `'arrow'`（当 `kind === 'shape'` 时生效）
   - `x, y, width, height`: 画布世界坐标系下的包围盒位置与尺寸（支持直接拖拽与缩放）
   - `points?`: 归一化相对坐标点集 `Array<{ x: number; y: number }>`（取值 `0~1`，缩放包围盒时自动映射）
   - `color`: 主题色值（如 `#EF4444` 预警红、`#F59E0B` 荧光黄、`#3B82F6` 科技蓝等）
   - `strokeWidth`: 笔触粗细（`2` | `4` | `6` | `14`）
   - `opacity`: 透明度（普通画笔 `1.0`，荧光笔 `0.38`）
   - `text?`: 作战便签正文内容或图形内部批注文字
   - `stamp?`: 作战便签战术印章类型（`'breakthrough'` 重点突破 | `'risk'` 风险预警 | `'verify'` 待核实 | `'intel'` 情报纪要）
   - `zIndex, locked, hidden, createdAt`: 标准图层控制字段
2. **瞬态激光笔轨迹 (`LaserTrail`)**：
   - 仅保存在画布组件内存中（不写入数据库），包含采样点时间戳序列，通过 `requestAnimationFrame` 自动清理超过 `1200ms` 的尾部节点，实现丝滑消隐。

### 交互与状态映射关系

- **绘制态（MouseDown $\rightarrow$ MouseMove $\rightarrow$ MouseUp）**：
  - 在 `pen` / `highlighter` 模式下实时采集指针的世界坐标，若开启「一笔成型」则在松手瞬间运行几何分类器：匹配成功则转化为标准 `shape`（矩形/椭圆/直线/战术箭头），否则经 RDP 简化后保存为平滑贝塞尔曲线 `pen` 对象并压入 `history` 撤销栈。
- **套索增强态（Lasso Mode）**：
  - **套索刀切连线**：当处于「切线子模式」（或按住 `Alt`）绘制轨迹时，实时计算手绘折线与画布上每条可见关系连线贝塞尔采样段的相交情况，被划过的连线高亮标红，松手后批量移除对应连线并弹出 Toast 提示。
  - **套索一键建组**：当套索闭合区域达到最小尺寸（`120×90`）时，在选中面板提供「按套索区域创建分组框」按钮（或空圈直接建框），自动根据圈选边界生成 `GroupFrame`。
- **选中与编辑态**：
  - 点击任意 `CanvasAnnotation` 即可选中，展示四角缩放手柄与顶部悬浮工具条（切换颜色、线宽、印章标签、图层置顶/置底、锁定、删除）；双击 `sticky` 作战便签可直接内联编辑多行文本。
- **图层与导出联动**：
  - 图层管理面板新增「批注」筛选标签页；画布底部/顶部与导出中心同步提供「显示/隐藏战术批注」开关，勾选时 SVG/PNG/PDF 导出完整渲染所有可见的自由笔迹、几何图形与作战便签。
